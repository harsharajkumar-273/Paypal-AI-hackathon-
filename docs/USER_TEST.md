# First-time participant rehearsal

Run this after a stable hosted build is available. Ask someone who has not seen ProofPay to try the public private-demo flow. This document is a test protocol, not a record of completed interviews.

## Ten-minute session

1. Give the participant only the hosted URL and the task: “Commission a booking-form repair, understand why the first delivery cannot be paid, and get the corrected job paid.” Avoid explaining the navigation.
2. Observe the agreement, explicit rule consent, failed reservation, screenshot evidence, correction, and simulated receipt. Record where they hesitate or request help.
3. Ask them to find the proposed $2 increase and describe any other changed obligation before deciding whether to accept it.
4. Ask them to report a problem with the paid demo and explain what happens to future automatic payments.
5. Ask: “Was any payment real?”, “Who controls acceptance checks?”, “What would you need before trusting automatic payment?”, and “What was hardest to understand?”

Use a fresh demo workspace for each participant. Obtain permission before recording or quoting them. Never provide merchant invitation secrets, real account credentials, or another participant's records.
